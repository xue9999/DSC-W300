## Next artifact and first analysis

The next productive transition requires actual W300-specific implementation evidence rather than another broad search or a speculative device command. When an artifact becomes available:

1. Preserve the original bytes and source context; inspect its archive, embedded model/version and dependencies without running the program. A filename or PID match alone is insufficient.
2. Start with the documented **Destination Check** read path, then trace its SeusEX calls, response validation and destination representation.
3. Follow the original-board/service-board condition and the exact write path. The manual's service-board restriction remains unresolved for the user's original board.
4. Identify the narrowest language-only update if available. If destination conversion is necessary, establish all affected fields and actual encoding. The manual's U2 (English/NTSC) and CEE8 (English/PAL) labels are not raw write values.
5. Establish affected-data backup, restoration, commit and post-restart readback before preparing a hardware write procedure. SERIAL and ADJBAK files have distinct documented scopes and do not establish complete recovery coverage.

The program revision matters: the retained Sony manual records a Destination Data Write correction in 1.2r03 and an Adjustment Mode entry correction in 1.3r04. Earlier versions require comparison rather than silent substitution. See `service-board-audit.md` for source pages and operation details.

## Resumption rule

Subsequent offline inspection established an additional acquisition candidate: [G3 path-based FileControl reads](g3-file-read/README.md). This narrows the earlier dependency on an externally obtained package: actual W300 code might instead be acquired from the owner's camera after separately qualifying its service lifecycle and transfer. The finding does not qualify W300 or change the user's current no-camera constraint.

Resume package acquisition when there is a new actual file, attachment locator, repository reference, archive inventory or legitimate service-source access. Do not repeat the same catalogs or treat more comparative G3 decoding as W300 qualification. The separate receiving-PC inventory/INQUIRY session remains useful for identity evidence, but it cannot by itself supply the missing language command or prove persistent English menus.
